# The Five Kids Wear — Front-end

متجر إلكتروني لملابس الأطفال — **الواجهة الأمامية فقط** (لا يوجد باك إند).
Front-end only kids-wear storefront. No backend, no database, no real payments.

## التشغيل / Running

```bash
npm install
npm run dev
```

الموقع يعمل على `http://localhost:5173` — The site runs at `http://localhost:5173`.

```bash
npm run build     # إنتاج / production build → dist/
npm run preview   # معاينة البناء / preview the build
```

## التقنيات / Stack

React 19 · TypeScript · Vite 6 · Tailwind CSS v4 · React Router 7. لا توجد مكتبات UI جاهزة — كل المكونات مكتوبة يدوياً.

## اللغات / Languages

عربي (RTL) + إنجليزي (LTR)، يتبدلان من زر اللغة في الشريط العلوي، والاختيار محفوظ في `localStorage`.
كل النصوص في `src/i18n/translations.ts`، والاتجاه يُضبط تلقائياً على `<html dir>`.
التخطيط كله يستخدم خصائص CSS المنطقية (`start`/`end`, `ms`/`me`) فيبدّل اتجاهه تلقائياً.

## الحالة / State

السلة والمفضلة والطلبات وتسجيل الدخول كلها **وهمية** ومحفوظة في `localStorage`
(`src/context/StoreContext.tsx`). عند إضافة الباك إند، استبدل هذا الملف بنداءات API.

بيانات المنتجات التجريبية في `src/data/catalog.ts` — ١٢ منتج بصور حقيقية من مجلد `products`.

## سيكشن الهيرو / Hero section

الهيرو مقسوم لنصين: **الدب + الكلام** في نص، و**كولاج صور بولارويد** (`src/components/PhotoCollage.tsx`) في النص التاني.
الشعار مش موجود في الهيرو (موجود في الهيدر بس) — الدب واخد مكانه.

- **٧ كروت صور** مائلة بشريط لاصق، بتدخل بأنيميشن متتابع (`deal-in`) وبتفضل تطفو (`bob`)
- **بارالاكس بالماوس** — كل كارت بيتحرك بمقدار مختلف حسب `--depth` (`src/components/usePointerParallax.ts`)
- **هوفر** على أي كارت: يعتدل ويكبر ويطلع لقدام، والكارت لينك لصفحة المنتج
- **خلفية** فيها ٣ دوائر ناعمة بتتحرك ببطء (`drift`) + قلوب ونجوم وتاج وطيارة ورق طايرين
- **شارة علوية** فيها لمعة بتعدي عليها (`shimmer`)، و**زر تسوق الآن** فيه لمعة عند الهوفر
- **الدب** في مكان الشعار فوق الكلام، بيطفو ببطء وبيتحرك مع الماوس
- كل الأنيميشنز بتتوقف تلقائياً مع `prefers-reduced-motion`، والبارالاكس بيتلغي على شاشات اللمس

## الصور / Assets

كل الصور في `public/images/`:

- `logo.png` — الشعار
- `teddy-bear.webm` — فيديو الدب في الهيرو (صامت + لوب)
- `promo-kids.png` — بانر العروض
- `categories/` — صور الفئات · `products/` — المنتجات
- `avatars/` — `boy` و `girl` (شريط المميزات) · `bear` (الصفحات الفاضية و 404) · `arrow` (زخرفة الفوتر)

**الريبو فيه الصور المستخدمة بس.** الأصول الأصلية في روت الفولدر (`logo.png`, `bear avatar.png`,
`hero.png`, مجلد `products/` ...) موجودة على جهازك بس ومش مرفوعة — لأنها متكررة جوه
`public/images/` بأسماء إنجليزية، والريبو كان هيبقى ضعف الحجم من غير فايدة. الاستثناءات في `.gitignore`.

### ⚠️ ملاحظات مهمة عن الصور

**1. فيديو الدب لا يحتوي على شفافية حقيقية.**
الملف المسلَّم مرسوم عليه مربعات الشطرنج الرمادية (قناة الألفا فيه = 255 في كل البكسلات)، فلو
استُخدم داخل `<video>` عادي تظهر المربعات خلف الدب. الحل الحالي في
`src/components/TransparentVideo.tsx`: يُرسم الفيديو على `<canvas>` ويُشال كل بكسل رمادي محايد
(‏R≈G≈B وفاتح) لحظياً. النتيجة نظيفة، لكن **الأفضل** توفير نسخة WebM بقناة ألفا حقيقية
(VP9 + alpha) — وقتها يمكن استبدال المكوّن بوسم `<video>` عادي.

**2. بانر العروض `promo-kids.png` عليه نص عربي مطبوع جوه الصورة.**
البانر بيتعرض **كامل** بنسبته الأصلية (2170×725) من غير أي قص أو نص فوقه — الزر بس.
النص المطبوع في يسار الصورة، فالزر متحطوط تحته بإحداثيات **فيزيائية** ثابتة
(`cta: { left, top }` في `src/components/PromoSlider.tsx`) عشان يفضل مظبوط في العربي والإنجليزي.
على الموبايل البانر بيبقى ~110px ارتفاع، فالزر بينزل تحت الصورة بدل ما يكون فوقها.

> لأن النص مطبوع جوه الصورة، فهو عربي في النسخة الإنجليزية كمان. لو عايز إنجليزي، ابعت نسخة
> إنجليزية من البانر.

**البانر بيقبل أكتر من صورة:** ضيف صور في مصفوفة `banners` في `PromoSlider.tsx` والأسهم والنقط
بترجع تشتغل لوحدها. دلوقتي فيه صورة واحدة فمخفيين.

**3. `hero.png` مش مستخدم خالص** — عليه نص عربي مطبوع كمان، والهيرو مبني بالكامل بـ CSS،
فمش مرفوع على الريبو.
