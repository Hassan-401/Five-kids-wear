# Five Kids Wear

متجر إلكتروني لملابس الأطفال — **واجهة + باك إند كامل** على Cloudflare، بلوحة تحكم للمالك.
A bilingual kids-wear store — SPA plus a full backend on Cloudflare, with an owner dashboard.

- **الواجهة / Storefront** — React 19 · TypeScript · Vite 6 · Tailwind v4 · React Router 7
- **الباك إند / Backend** — Cloudflare Worker + D1 (SQLite) + R2 (صور المنتجات)
- **الشحن / Shipping** — مربوط بـ **بوسطة** (إنشاء شحنة، رقم تتبع، تحديث الحالة أوتوماتيك)
- **مفيش حسابات عملاء ومفيش تقييمات** — No customer accounts, no product reviews

## التشغيل محلياً / Running locally

### الواجهة بس / Front-end only

```bash
npm install
npm run dev
```

`http://localhost:5173` — الموقع بيشتغل لوحده. لو الـ API مش شغال، الكتالوج بيرجع تلقائياً
لبيانات `src/data/catalog.ts` وكل الصفحات تشتغل عادي (من غير طلبات ولا لوحة تحكم).

### بالباك إند / With the backend

في تيرمينال أول — جهّز قاعدة البيانات المحلية مرة واحدة، وبعدين شغّل الـ Worker:

```bash
npm run db:schema
npx wrangler dev
```

وفي تيرمينال تاني:

```bash
npm run dev
```

Vite بيمرّر `/api` و `/media` للـ Worker على `127.0.0.1:8787` (`vite.config.ts`).

لتسجيل الدخول للوحة التحكم محلياً، اعمل ملف `.dev.vars` في روت المشروع (مش مرفوع على جيت):

```
ADMIN_USERNAME = "admin"
ADMIN_PASSWORD = "اكتب-كلمة-مرور-قوية"
BOSTA_API_KEY = "مفتاح-بوسطة"
BOSTA_WEBHOOK_SECRET = "اي-كلمة-طويلة"
```

آخر سطرين اختياريين — من غيرهم الموقع بيشتغل عادي وصفحات بوسطة بس هي اللي بتقول
إن المفتاح ناقص.

بعدين افتح `http://localhost:5173/admin` وسجّل دخول. أول تسجيل دخول ناجح بيعمل الحساب،
وبعدها المتغيرين دول بيتجاهَلوا وكلمة المرور بتتغير من صفحة الإعدادات بس.

### فحص الأنواع والبناء / Check & build

```bash
npm run check   # tsc للواجهة والـ Worker
npm run build   # → dist/
```

## النشر على Cloudflare / Deploying

كل حاجة على Cloudflare: الدومين والاستضافة وقاعدة البيانات والصور.

**1. اعمل قاعدة البيانات والباكِت:**

```bash
npx wrangler d1 create five-kids-wear
npx wrangler r2 bucket create five-kids-wear-media
```

**2. حط `database_id` اللي ظهر لك في `wrangler.toml`** مكان `REPLACE_WITH_YOUR_D1_DATABASE_ID`.

**3. طبّق الجداول على القاعدة السحابية:**

```bash
npm run db:schema:remote
```

> ⚠️ ملف `worker/schema.sql` بيبدأ بـ `DROP TABLE` — شغّله على قاعدة فاضية بس، مش على قاعدة فيها طلبات.

**٣.ب التعديلات على قاعدة شغّالة / Migrations:**

القاعدة اللي فيها طلبات فعلاً مينفعش تتعمل من `schema.sql` تاني. التعديلات بعد أول نشر
بتتحط في `worker/migrations/` وبتتشغّل مرة واحدة:

```bash
npm run db:migrate:remote
```

`001_bosta.sql` بيضيف أعمدة بوسطة وروابط السوشيال ويظبّط أسعار الشحن. لو شغّلته مرتين
هيقول `duplicate column name` — ودي معناها إنه اتطبّق خلاص، مش إن فيه غلط.

**4. حط بيانات الدخول للوحة التحكم كأسرار (مش في الكود):**

```bash
npx wrangler secret put ADMIN_USERNAME
npx wrangler secret put ADMIN_PASSWORD
```

ولو هتربط بوسطة، حط مفتاحها كسر كمان (تفاصيل تحت في قسم بوسطة):

```bash
npx wrangler secret put BOSTA_API_KEY
npx wrangler secret put BOSTA_WEBHOOK_SECRET
```

**5. انشر:**

```bash
npm run cf:deploy
```

**6. اربط الدومين** (اختياري — الموقع بيشتغل من غيره على الرابط المجاني).

الرابط المجاني شكله `<اسم الموقع>.<اسم الحساب>.workers.dev`، و**اسم الحساب مشترك بين كل مشاريع
الحساب** ومينفعش يتعمل واحد مستقل لكل مشروع. الحل الوحيد لإخفائه هو دومين حقيقي:

1. ضيف الدومين على Cloudflare من **Workers & Pages → الـ Worker → Domains**
   (من نفس الصفحة تقدر تشتري دومين جديد ويتربط أوتوماتيك)
2. شيل علامة التعليق عن `workers_dev` و `[[routes]]` في `wrangler.toml` وحط الدومين الحقيقي
3. `npm run cf:deploy`

`workers_dev = false` بيقفل الرابط المجاني ورابط المعاينة مع بعض. **متفعّلهوش قبل ما الدومين
يتربط**، وإلا الموقع هيفضل من غير أي رابط.

**7. افتح `https://<الدومين>/admin`**، سجّل دخول، واضغط **استيراد المنتجات** في صفحة النظرة العامة
عشان تنقل الـ ٥١ منتج والأقسام لقاعدة البيانات. بعد كده القاعدة هي المصدر الوحيد للبيانات.

## لوحة التحكم / Dashboard

على `/admin`، محمية بكوكي جلسة، ومنفصلة عن تصميم المتجر (وبتتحمّل لوحدها فمش محمّلة على الزباين).

| الصفحة | بتعمل إيه |
| --- | --- |
| **نظرة عامة** | عدد الطلبات، الإيرادات، عدد المنتجات، اللي نفذ، الطلبات حسب الحالة، آخر ٨ طلبات، وزرار استيراد الكتالوج |
| **الطلبات** | بحث بالرقم/الاسم/التليفون، فلتر بالحالة، فتح الطلب بتفاصيله، تغيير الحالة، حذف |
| **المنتجات** | إضافة وتعديل وحذف، رفع صور، ألوان ومقاسات، سعر وسعر قبل الخصم، إخفاء/إظهار، متوفر/نفذ |
| **الأقسام** | إضافة وتعديل وحذف، صورة وخلفية البلاطة والترتيب (القسم اللي فيه منتجات مبيتحذفش) |
| **الشحن** | سعر لكل محافظة (٢٨ محافظة)، ربط كل محافظة بمدينة في بوسطة، تفعيل/إيقاف أي محافظة، حد الشحن المجاني، سعر افتراضي |
| **الإعدادات** | تليفون وبريد وواتساب المتجر، روابط السوشيال، إعدادات بوسطة، **حسابات الدخول**، فتح/قفل الطلبات، الدفع عند الاستلام، تغيير كلمة المرور |

### حسابات الدخول / Dashboard accounts

من **الإعدادات → حسابات الدخول** تقدر تضيف أي عدد من الحسابات (اسم الدخول ممكن يكون إيميل).
**مفيش صلاحيات مقسّمة** — أي حساب هنا بيقدر يعمل كل حاجة، بما فيها إضافة وحذف حسابات تانية،
فمتضيفش غير ناس واثق فيهم. الحساب اللي انت داخل بيه، وآخر حساب فاضل، مبيتحذفوش عشان
اللوحة متتقفلش في وش الكل.

اللوحة بتتكلم عربي وإنجليزي زي المتجر، وبتتبدّل من نفس الزرار.

### الأمان / Security

- كلمة المرور متخزنة PBKDF2-SHA256 (١٠٠ ألف دورة — ده أقصى حد بيسمح بيه Workers) — مش نص صريح.
- الكوكي `HttpOnly` + `SameSite=Strict` + `Secure` على https، والمخزَّن في القاعدة هو SHA-256 للتوكن.
- كل مسارات `/api/admin/*` بتعدي على بوابة واحدة في `worker/src/index.ts` — مسار جديد مينفعش ينسى الحماية.
- **أسعار الطلبات بتتحسب على السيرفر** من قاعدة البيانات؛ المتصفح بيبعت أرقام المنتجات والكميات بس،
  فمحدش يقدر يغيّر السعر من عنده.
- تتبع الطلب محتاج رقم الطلب **ورقم التليفون** مع بعض.

## البيانات / Data

### مفيش حسابات عملاء

العميل بيطلب باسمه ورقم تليفونه وعنوانه — من غير تسجيل ولا كلمة مرور. بعد الطلب بياخد رقم زي
`FKW-10248` ويتابع بيه من `/track`. صفحات `/login` و `/register` و `/account` اتشالت خالص.

### مفيش تقييمات

النجوم وعدد المراجعات اتشالوا من المنتجات ومن الواجهة ومن قاعدة البيانات. الترتيب بـ«الأكثر شهرة»
بقى معتمد على حقل `popularity` اللي بيتظبط من اللوحة.

### الأسعار

- **كل بيجامة شتوي → ٥٠٠ ج.م** (٢٣ صنف: البيجامات المطبوعة وأطقم الرجلان الشتوي)
- **كل بكيت سلوبتات (بودي) → ٤٠٠ ج.م** (١١ بكيت)

الباقي زي ما هو. كل الأسعار قابلة للتعديل من اللوحة.

### أسعار الشحن / Shipping prices

أسعار بوسطة المنشورة **مش شاملة ضريبة القيمة المضافة ١٤٪**، والسعر بيتحدد بـ«القطاع»
(`sector`) اللي بوسطة نفسها بترجّعه مع كل مدينة في `GET /api/v0/cities`:

| القطاع | المحافظات | بوسطة | + ١٤٪ | الموقع بياخد |
| --- | --- | ---: | ---: | ---: |
| ١ | القاهرة، الجيزة | ٩٧ | ١١٠٫٥٨ | **١١٥** |
| ٢ | الإسكندرية، البحيرة | ١٠٢ | ١١٦٫٢٨ | **١٢٠** |
| ٣ | الدلتا والقناة (١٠ محافظات) | ١١٠ | ١٢٥٫٤٠ | **١٣٠** |
| ٤ و ٥ | الصعيد والبحر الأحمر ومطروح | ١٤٠ | ١٥٩٫٦٠ | **١٦٥** |
| ٦ و ٧ | الساحل الشمالي، سيناء، الوادي الجديد | — | — | **١٧٥** |

> القطاعان ٦ و ٧ **مش في جدول أسعار بوسطة المنشور**، فالـ ١٧٥ رقم مؤقت لحد ما بوسطة
> تسعّرهم. **شمال سيناء متقفلة** لأن بوسطة بترجّع `dropOffAvailability: false` عليها.

وحد الشحن المجاني بقى **١٥٠٠ ج.م** بدل ١٠٠٠ — عند ١٠٠٠ كان طلب من قطعتين بياخد شحن
مجاني بيكلّف ١١٥–١٧٥ من جيب المتجر.

### الكتالوج

`src/data/catalog.ts` بقى **بيانات أولية** بتتقري من مكانين:

- `worker/src/seed.ts` — بينقلها للقاعدة أول مرة (زرار «استيراد المنتجات»)
- `src/context/CatalogContext.tsx` — بيرجع لها لو الـ API مش شغال

بعد الاستيراد، **قاعدة البيانات هي المصدر**؛ الملف ده بيفضل موجود عشان التشغيل المحلي بس.

### الجداول / Schema

`worker/schema.sql`: `categories`, `products`, `orders`, `order_items`, `shipping_rates`,
`settings`, `admins`, `sessions`. الأسعار كلها أرقام صحيحة بالجنيه، والقوائم (مقاسات، ألوان، صور)
متخزنة JSON. والتعديلات اللي بعد أول نشر في `worker/migrations/`.

## بوسطة / Bosta

الربط اختياري بالكامل: من غير مفتاح، المتجر شغّال عادي وصفحات بوسطة بس هي اللي بتقول
إن المفتاح ناقص.

**التشغيل:**

1. `npx wrangler secret put BOSTA_API_KEY` — المفتاح من داشبورد بوسطة:
   **Settings → API Integration**
2. `npx wrangler secret put BOSTA_WEBHOOK_SECRET` — أي كلمة طويلة من اختيارك
3. من **الإعدادات** في اللوحة: فعّل **الشحن مع بوسطة** واختار **مكان الاستلام**
4. من **الشحن**: اتأكد إن كل محافظة مربوطة بمدينة في بوسطة (متظبّطة كلها من `001_bosta.sql`)

**الاستخدام اليومي:** من **الطلبات** افتح الطلب واضغط **اشحن مع بوسطة**. بتتعمل شحنة
بنفس بيانات العميل، والتحصيل بيساوي إجمالي الطلب لو الدفع عند الاستلام، ورقم التتبع
بيتخزن ويظهر للعميل في صفحة `/track`.

ولو عايز كل طلب جديد يتشحن لوحده من غير ما تدوس، فعّل **اشحن كل طلب جديد أوتوماتيك**.
الشحن الأوتوماتيك متعمّد إنه «أحسن مجهود»: لو بوسطة وقعت، الطلب بيتسجّل عادي وتشحنه بإيدك.

**تحديث الحالة أوتوماتيك:** ابعت الرابط ده لدعم بوسطة:

```
https://<الدومين>/api/bosta/webhook/<BOSTA_WEBHOOK_SECRET>
```

بوسطة **مش بتوقّع الويب‌هوك**، فالكلمة السرية اللي في الرابط هي الحاجة الوحيدة اللي
بتفرق بين نداء حقيقي وأي حد على الإنترنت — متنشرهاش. حالات بوسطة (٢٢ حالة) بتتحوّل
لأربع حالات في الموقع، والحالات المش معروفة (زي `Exception`) بتتسجّل من غير ما ترجّع
الطلب لورا في نظر العميل.

> **اللي لسه محتاج تجربة:** كل حاجة في الربط اتجرّبت على مفتاح بوسطة الحقيقي —
> قائمة المدن، مكان الاستلام، الويب‌هوك، وكل حالات الرفض — **ماعدا إنشاء شحنة فعلية**،
> لأنها بتعمل أوردر حقيقي على حساب العميل. أول شحنة جرّبها بنفسك وتأكد إنها ظهرت في
> داشبورد بوسطة.

## الـ API

| المسار | |
| --- | --- |
| `GET /api/catalog` | كل حاجة المتجر محتاجها في نداء واحد |
| `GET /api/products/:slug` | منتج واحد |
| `GET /api/shipping` | جدول الشحن |
| `POST /api/orders` | إنشاء طلب (الأسعار بتتحسب على السيرفر) |
| `GET /api/orders/:id?phone=` | تتبع طلب (أي شكل لرقم التليفون بيتقبل) |
| `POST /api/bosta/webhook/:secret` | بوسطة بتنادي عليه لما الشحنة تتحرك |
| `/api/admin/*` | اللوحة — محتاجة جلسة |
| `GET /media/*` | صور المنتجات من R2 |

أي مسار تاني بيرجع الـ SPA، فالروابط العميقة بتشتغل مع الـ refresh.

## الهوية / Theme

- **الاسم** `Five Kids Wear` و**اللوجو** `public/images/logo.webp`.
- **الألوان** لبني وبينك (`sky-*` و `pink-*` في `src/index.css`) والكحلي للنصوص والحدود.
- **الاسم مكتوب بخط الكرتون** في `src/components/Wordmark.tsx` (خط `Luckiest Guy` بإطار كحلي).
- **الزخارف** نجوم وأقمار وبرق (`src/components/Decor.tsx`) ونقط نجوم على الخلفيات (`.star-dust`).
- **الزراير** ليها "شفة" أغمق من تحت وبتنضغط لما تدوس.

> **ملاحظة:** صور الشخصيات في `public/images/characters/` (في الهيرو، وكروت الأقسام، والفوتر،
> وصفحة 404، والصفحات الفاضية) لسه من الطابع القديم. لو عايز تشيلها أو تستبدلها بصور منتجات
> أو رسومات خاصة بالبراند، قول وأغيّرها.

## اللغات / Languages

عربي (RTL) وإنجليزي (LTR) بالكامل — المتجر واللوحة. الزرار في الشريط العلوي، والاختيار محفوظ في
`localStorage`، والاتجاه بيتظبط على `<html dir>`. نصوص المتجر في `src/i18n/translations.ts`،
ونصوص اللوحة مكتوبة بـ `pick("عربي", "English")` جنب الواجهة نفسها.

> الاستثناء الوحيد: الكلام المطبوع **جوه صورة** بانر العروض عربي في النسختين.

## الصور / Assets

كل الصور المستخدمة في `public/images/` — اللوجو، الشخصيات، بانر العروض، صور المنتجات،
وصور قسمَي الرجالي والحريمي. صور المنتجات الجديدة اللي بترفعها من اللوحة بتروح **R2**
وبتتقدّم على `/media/...`.

**الريبو فيه الصور المستخدمة بس.** الأصول الأصلية في روت الفولدر (`logo.webp`,
`Promotional Section home.png`, `original products images/`, `products/`, `men/`, `women/`)
موجودة على جهازك ومش مرفوعة — الاستثناءات في `.gitignore`.
