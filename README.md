# Five PJ Masks — Front-end

متجر إلكتروني لملابس الأطفال بطابع كرتون **PJ Masks** — **الواجهة الأمامية فقط** (لا يوجد باك إند).
Front-end only kids-wear storefront themed on PJ Masks. No backend, no database, no real payments.

## التشغيل / Running

```bash
npm install
npm run dev
```

الموقع يعمل على `http://localhost:5173` — The site runs at `http://localhost:5173`.

```bash
npm run build     # إنتاج / production build → dist/
npm run preview   # معاينة البناء / preview the build
```

## التقنيات / Stack

React 19 · TypeScript · Vite 6 · Tailwind CSS v4 · React Router 7. لا توجد مكتبات UI جاهزة — كل المكونات مكتوبة يدوياً.

## اللغات / Languages

الموقع **عربي وإنجليزي بالكامل**: عربي (RTL) + إنجليزي (LTR)، يتبدلان من زرار **English / العربية** في
الشريط العلوي، والاختيار محفوظ في `localStorage`. كل النصوص في `src/i18n/translations.ts` (وأسماء
المنتجات وأوصافها ليها نسخة عربي وإنجليزي في `src/data/`)، والاتجاه يُضبط تلقائياً على `<html dir>`.
التخطيط كله يستخدم خصائص CSS المنطقية (`start`/`end`, `ms`/`me`) فيبدّل اتجاهه تلقائياً.

> الاستثناء الوحيد: الكلام المطبوع **جوه صورة** بانر العروض عربي في النسختين — ده جزء من الصورة نفسها.

## الهوية / Theme

الموقع واخد طابع كرتون PJ Masks — أبطال الليل:

- **الاسم** `Five PJ Masks` و**اللوجو** `public/images/logo.webp`.
- **الألوان الأساسية لبني وبينك** (`sky-*` و `pink-*` في `src/index.css`)، والكحلي بتاع سما الليل في
  الكرتون (`navy-*`) للنصوص والحدود بس.
- **الاسم مكتوب بخط الكرتون** (`src/components/Wordmark.tsx`): خط `Luckiest Guy`، حروف كبيرة بإطار كحلي
  وظل نازل لتحت زي اللوجو (`.toon-word`). عناوين السكاشن بنفس الروح بس أخف (`.toon-title`).
  الخط لاتيني بس، فالعناوين العربي بتنزل تلقائياً على `Baloo Bhaijaan 2`.
- **الزراير** ليها "شفة" أغمق من تحت وبتنضغط فيها لما تدوس، زي زراير الكرتون.
- **الزخارف** نجوم وأقمار وبرق (`src/components/Decor.tsx`) بدل القلوب، ونقط نجوم بيضا على الخلفيات
  (`.star-dust`).
- **الشخصيات** في `public/images/characters/`:
  - الفريق كله في الهيرو وفي كارت فئة **البيجامات** (أبطال البيجامات)
  - **كات بوي** في كارت **ملابس أولاد**، و**أوليت** في كارت **ملابس بنات** — واقفين على قمر منوّر
  - كات بوي وجيكو في شريط المميزات، وأوليت طايرة في الفوتر
  - كات بوي في صفحة 404 و"مفيش نتائج"، وجيكو في السلة والمفضلة الفاضية

## الحالة / State

السلة والمفضلة والطلبات وتسجيل الدخول كلها **وهمية** ومحفوظة في `localStorage`
(`src/context/StoreContext.tsx`). عند إضافة الباك إند، استبدل هذا الملف بنداءات API.

منتجات الأطفال في `src/data/catalog.ts` — الصور حقيقية والبيانات المكتوبة وهمية،
التفاصيل في [قسم منتجات الأطفال](#منتجات-الأطفال--kids-catalogue).

## سيكشن الهيرو / Hero section

الهيرو مقسوم لنصين على نفس فكرة الصورة المرجعية:

- **نص البراند**: **صورة الشخصيات كلها** وتحتها **اسم Five PJ Masks كبير** راكب على رجلين الشخصيات
  زي اللوجو ← جملة قصيرة ← أيقونات السوشيال ← زرار **تسوق الآن** + زرار المفضلة.
- **النص التاني**: **كولاج صور بولارويد** للمنتجات (`src/components/PhotoCollage.tsx`) بشريط لاصق
  لبني وبينك بالتبادل. **الكولاج بيختفي على الموبايل** (`hidden sm:block`) ويظهر من التابلت وأكبر.
- **الخلفية** تدرّج من اللبني للبينك، عليها نقط نجوم وقمر منوّر ونجوم بتلمع وبرق طاير.
- **أنيميشن**: الكروت بتدخل ورا بعض (`deal-in`) وبتطفو (`bob`)، والشخصيات بتطفو برضو، و**بارالاكس
  بالماوس** (`src/components/usePointerParallax.ts`).
- كل الأنيميشنز بتتوقف تلقائياً مع `prefers-reduced-motion`، والبارالاكس بيتلغي على شاشات اللمس.

## منتجاتنا / Our products

شريط كروت في الرئيسية تحت الفئات (`src/components/ProductsMarquee.tsx`) على شكل الصورة المرجعية:

- كل كارت صورة منتج حقيقية، وتحتها تدرّج بلون الكارت، وأيقونة في الركن، والاسم بالعربي والإنجليزي
  (اللغة المختارة كبيرة والتانية صغيرة تحتها).
- **الشريط بيتحرك ناحية الشمال على طول** (في العربي والإنجليزي)، و**بيقف لما الماوس ييجي عليه** (أو
  لما تتنقل فيه بالكيبورد)، وبيكمل لما الماوس يمشي. الأسهم بتحرك كارت كارت.
- اللستة متكررة مرتين، فاللف مالوش آخر ومن غير قفزة.
- مع `prefers-reduced-motion` الشريط مبيتحركش لوحده — الأسهم بس.
- لتعديل الكروت (الاسم، الصورة، اللينك، اللون، الأيقونة) عدّل مصفوفة `items` في نفس الملف.

## قسمَي الرجال والنساء / Men & Women

القسمين دول ليهم **ديزاين مستقل تماماً** عن باقي الموقع (أبيض ومحايد) ومش واخدين طابع الكرتون.

- **الخلفيات كلها بيضا** والألوان محايدة. اللي بيفرّق بين القسمين هو **الخط والشكل** مش اللون.
- **الستايل** في `src/styles/departments.css`، متغيّرات مربوطة بالكلاسات `.dept-men` و `.dept-women`.
- **رجالي** — حواف حادة، خط `Tajawal`/`Inter`، بلاطات أقسام مربّعة والاسم فوق الصورة.
- **نسائي** — خط `Amiri`/`Cormorant Garamond` (سيريف)، صور بإطار **قوس**، والاسم تحت الصورة.
- **صفحة القسم فيها حاجتين بس**: الأقسام الفرعية + أحدث القطع.
- **مفيش منتجات دلوقتي** — المنتجات الافتراضية اتشالت، و`deptProducts` في `src/data/departments.ts`
  فاضية. مكان "أحدث القطع" وصفحات الأقسام الفرعية بيظهر فيها "القطع الجديدة في الطريق"
  (`src/components/dept/DeptEmpty.tsx`). أول ما تضيف منتجات في `deptProducts` الكروت بترجع تظهر
  لوحدها بنفس الشكل (`src/components/dept/DeptProductCard.tsx`).

## منتجات الأطفال / Kids catalogue

الصور **حقيقية** — من مجلد `original products images` اللي فيه صور منتجات GEPS. البيانات
المكتوبة (الأسعار، الأوصاف، التقييمات، عدد المراجعات) **وهمية** لحد ما تيجي البيانات الحقيقية.

**تنظيف الصور:** المجلد كان فيه ٩١ صورة → طلعت **٧٥ صورة فريدة** (١٦ صورة متكررة بالبايت
اتشالت)، وبعدها اتشال:
- سليدين بريزنتيشن من Canva (مش منتجات)
- نسخة مكررة بصرياً من طقم CODE 013

الباقي **٧٢ صورة** موزّعين على **٥١ منتج** في `src/data/catalog.ts`. كل منتج له `images[]`،
والصور المتعددة لنفس المنتج (صورة كاملة + تفاصيل + البنطلون لوحده) بقت جاليري في صفحة المنتج.

**الفئات** اتظبطت على المنتجات الموجودة فعلاً:

| الفئة | المنتجات |
| --- | --- |
| `pajamas` بيجامات | ١٣ بيجامة شتوي مطبوعة + ١٠ طقم رجلان (أكواد GEPS) |
| `newborn` مواليد | بكياتات بودي وفانلات + رومبيرات + بودي فردي |
| `boys` أولاد | أطقم صيفي (سبايدرمان، سونيك) |
| `girls` بنات | طقم صيفي ميني + بكياتات تيشيرتات + فانلات |

> فئة `accessories` اتشالت لأن مفيش ولا صورة إكسسوار في اللي وصل، ومكانها بقى `newborn`
> (مواليد) — دي أكبر مجموعة في الصور. لو عندك إكسسوارات ابعت صورها وأرجّعها.

**المقاسات** بقت زي اللي مطبوع على المنتجات: سنوات (٢–١٦) للبيجامات، حروف (M–2XL) لبعض
أطقم الرجلان، وشهور (NB, 1-3 ... 18-24) لخط المواليد.

## الصور / Assets

كل الصور في `public/images/`:

- `logo.webp` — الشعار (مصغّر لـ 900px عرض)
- `characters/` — `team` (الفريق كله)، `catboy`، `owlette`، `gekko` (مصغّرين بنفس الشفافية)
- `promo-home.webp` — بانر العروض (الأطفال لابسين ماسكات)، متحوّل من `Promotional Section home.png`
  (٢ ميجا PNG → ~٢٠٠ كيلو webp بنفس المقاس)، وصورته برضو في نص كولاج الهيرو
- `categories/` — `newborn.jpg` و `offers.png` (باقي الفئات بتستخدم الشخصيات)
- `products/` — صور المنتجات الحقيقية (`<slug>-1.jpg` ... )
- `men/` — `men-1..3` · `women/` — `women-1..3` (بلاطات الأقسام الفرعية)

**الريبو فيه الصور المستخدمة بس.** الأصول الأصلية في روت الفولدر (`logo.webp`،
`Promotional Section home.png`، مجلد `pj masks images/`، `original products images/`، `products/`،
`men/`، `women/` ...) موجودة على جهازك بس ومش مرفوعة — نسخها المستخدمة موجودة جوه `public/images/`
بأسماء إنجليزية. الاستثناءات في `.gitignore`. اللوجو القديم وفيديو الدب وصور الأفاتار والبانر القديم
ورسومات فئات الأولاد والبنات والبيجامات القديمة اتشالوا لأن الطابع الجديد مبقاش بيستخدمهم.

### ⚠️ ملاحظات مهمة عن الصور

**1. بانر العروض عليه نص عربي مطبوع جوه الصورة.**
البانر بيتعرض **كامل** بنسبته الأصلية (2170×725) من غير أي قص أو نص فوقه — الزر بس.
النص المطبوع في يسار الصورة، فالزر متحطوط تحته بإحداثيات **فيزيائية** ثابتة
(`cta: { left, top }` في `src/components/PromoSlider.tsx`) عشان يفضل مظبوط في العربي والإنجليزي.
على الموبايل البانر بيبقى ~110px ارتفاع، فالزر بينزل تحت الصورة بدل ما يكون فوقها.

> لأن النص مطبوع جوه الصورة، فهو عربي في النسخة الإنجليزية كمان. لو عايز نسخة إنجليزية من البانر
> ابعتها وأخلي كل لغة تعرض صورتها.

**البانر بيقبل أكتر من صورة:** ضيف صور في مصفوفة `banners` في `PromoSlider.tsx` والأسهم والنقط
بترجع تشتغل لوحدها. دلوقتي فيه صورة واحدة فمخفيين.

**2. `hero.png` مش مستخدم خالص** — عليه نص عربي مطبوع، والهيرو مبني بالكامل بـ CSS،
فمش مرفوع على الريبو.
